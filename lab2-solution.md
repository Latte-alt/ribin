# Лабораторная работа № 2

## Базовая настройка IP-телефонов в Cisco Packet Tracer

**Цель:** собрать сеть IP-телефонии, настроить DHCP и Cisco CallManager Express, назначить телефонам внутренние номера и проверить звонки.

**Задание:** [2лаб.docx](https://github.com/Latte-alt/ribin/blob/main/2%D0%BB%D0%B0%D0%B1.docx).

Команды маршрутизатора и коммутатора вводятся отдельно во вкладке **CLI**. Приглашения вида `Router(config)#` вводить не нужно. После `copy running-config startup-config` на запрос имени файла нажать **Enter**.

## 1. Сборка схемы

Добавить:

- маршрутизатор **Cisco 2811**;
- коммутатор **2960-24TT**, как на рисунке в методичке;
- два телефона **Cisco IP Phone 7960**.

В тексте методички также указан коммутатор 3560. Его можно использовать вместо 2960.

Соединить устройства кабелем **Copper Straight-Through**:

| Устройство и порт | Куда подключить |
| --- | --- |
| Router → FastEthernet0/0 | Switch → FastEthernet0/1 |
| Первый телефон → порт Switch | Switch → FastEthernet0/2 |
| Второй телефон → порт Switch | Switch → FastEthernet0/3 |

На телефоне использовать порт **Switch**, а не **PC**.

На каждом телефоне открыть **Physical** и перетащить **IP_PHONE_POWER_ADAPTER** в разъём питания. При использовании 2960-24TT телефонам необходим внешний адаптер.

## 2. Подготовка устройств

Для новых устройств этот шаг пропустить.

Если устройства использовались раньше, можно собрать схему в новом файле. Для очистки старых устройств выполнить команды ниже. **Они удаляют прежние настройки.**

### Маршрутизатор

```text
enable
erase startup-config
reload
```

Подтвердить удаление клавишей **Enter**. На предложение сохранить конфигурацию ответить **no**, затем подтвердить перезагрузку.

### Коммутатор

```text
enable
erase startup-config
delete flash:vlan.dat
reload
```

Имя файла и удаление подтвердить клавишей **Enter**. Если `vlan.dat` отсутствует, продолжить. На предложение сохранить конфигурацию ответить **no**, затем подтвердить перезагрузку.

После запуска маршрутизатора на вопрос:

```text
Would you like to enter the initial configuration dialog? [yes/no]:
```

Ответить `no` и нажать **Enter**. Затем при необходимости ещё раз нажать **Enter**, чтобы открыть командную строку.

## 3. Настройка коммутатора

Открыть **Switch → CLI** и ввести:

```text
enable
configure terminal
hostname SwitchA
no ip domain-lookup

interface fastEthernet0/1
switchport mode access
switchport access vlan 1
no shutdown
exit

interface range fastEthernet0/2 - 5
switchport mode access
switchport access vlan 1
switchport voice vlan 1
spanning-tree portfast
no shutdown
exit

end
copy running-config startup-config
```

На запрос `Destination filename [startup-config]?` нажать **Enter**.

- `Fa0/1` используется для подключения маршрутизатора.
- `Fa0/2–5` подготовлены для телефонов.
- `switchport voice vlan 1` задаёт голосовой VLAN по методичке.
- `spanning-tree portfast` ускоряет переход телефонных портов в рабочее состояние.

**VLAN 1 уже существует, отдельно создавать его не нужно.** По заданию голос и данные используют одну сеть; разделение на разные VLAN здесь не выполняется.

## 4. Настройка маршрутизатора

Открыть **Router → CLI** и ввести:

```text
enable
configure terminal
hostname CMERouter
no ip domain-lookup

interface fastEthernet0/0
ip address 192.168.10.1 255.255.255.0
no shutdown
exit

ip dhcp excluded-address 192.168.10.1 192.168.10.10

ip dhcp pool VOICE
network 192.168.10.0 255.255.255.0
default-router 192.168.10.1
option 150 ip 192.168.10.1
exit

telephony-service
max-ephones 5
max-dn 5
ip source-address 192.168.10.1 port 2000
auto assign 1 to 5
exit

ephone-dn 1
number 54001
exit

ephone-dn 2
number 54002
exit

ephone-dn 3
number 54003
exit

ephone-dn 4
number 54004
exit

ephone-dn 5
number 54005
exit

end
copy running-config startup-config
```

На запрос имени файла нажать **Enter**.

Созданы пять номеров. Для начальной схемы используются два, остальные можно назначить дополнительным телефонам.

### Назначение команд

| Команда | Назначение |
| --- | --- |
| `hostname CMERouter` | Изменяет имя маршрутизатора |
| `no ip domain-lookup` | Отключает попытки DNS-поиска при ошибках ввода |
| `ip address 192.168.10.1 255.255.255.0` | Назначает адрес интерфейсу маршрутизатора |
| `no shutdown` | Включает интерфейс |
| `ip dhcp excluded-address 192.168.10.1 192.168.10.10` | Исключает адреса `.1–.10` из выдачи DHCP |
| `ip dhcp pool VOICE` | Создаёт DHCP-пул |
| `network 192.168.10.0 255.255.255.0` | Задаёт сеть DHCP-пула |
| `default-router 192.168.10.1` | Передаёт клиентам адрес шлюза |
| `option 150 ip 192.168.10.1` | Передаёт телефонам адрес TFTP-сервера с настройками |
| `telephony-service` | Открывает настройки CallManager Express |
| `max-ephones 5` | Разрешает до пяти телефонов |
| `max-dn 5` | Разрешает до пяти телефонных линий |
| `ip source-address 192.168.10.1 port 2000` | Задаёт адрес и порт сервиса регистрации SCCP-телефонов |
| `auto assign 1 to 5` | Автоматически назначает линии телефонам |
| `ephone-dn` и `number` | Создают телефонную линию и задают её номер |

### Исправление команды из методички

В методичке одновременно указаны `auto assign 4 to 6` и `auto assign 1 to 5`, хотя `max-dn 5` разрешает только пять линий. В решении используется один согласованный диапазон:

```text
auto assign 1 to 5
```

### Маршрутизация

Дополнительные команды `ip route` не нужны: все устройства находятся в сети **192.168.10.0/24**. После включения интерфейса маршрут к непосредственно подключённой сети появится автоматически.

## 5. Регистрация телефонов

1. Переключиться в режим **Realtime**.
2. Дождаться зелёных индикаторов соединений.
3. Подождать примерно 30–60 секунд. Для ускорения можно нажать **Fast Forward Time**.
4. Открыть каждый телефон → **GUI**.
5. Проверить появление номеров **54001** и **54002**.

Номера назначаются по порядку регистрации. Первый телефон на схеме может получить `54002`. При звонках ориентироваться на номер на экране телефона.

IP-адрес можно посмотреть во вкладке **Config**, в настройках сетевого интерфейса телефона. Он должен принадлежать сети **192.168.10.0/24**.

## 6. Проверка конфигурации

### На маршрутизаторе

```text
enable
show ip interface brief
show ip dhcp binding
show ip route
show running-config
```

Ожидаемые результаты:

- `FastEthernet0/0` имеет адрес **192.168.10.1** и состояние **up/up**.
- В `show ip dhcp binding` отображаются адреса телефонов.
- В `show ip route` есть подключённая сеть **192.168.10.0/24**.
- В конфигурации присутствуют DHCP-пул, опция 150, телефонный сервис и внутренние номера.

Для просмотра зарегистрированных телефонов попробовать:

```text
show ephone registered
```

Если версия Packet Tracer не принимает эту команду, попробовать:

```text
show ephone
```

### На коммутаторе

```text
enable
show interfaces status
show vlan brief
show interfaces fastEthernet0/2 switchport
show interfaces fastEthernet0/3 switchport
show running-config
```

Подключённые порты должны находиться в состоянии **connected**. Для телефонных портов должны отображаться **Access VLAN 1** и **Voice VLAN 1**.

### Проверка доступности телефона

На маршрутизаторе выполнить, например:

```text
ping 192.168.10.11
```

**Вместо `192.168.10.11` подставить фактический адрес телефона из `show ip dhcp binding`.**

## 7. Проверка звонков

### Звонок 54001 → 54002

1. Открыть телефон с номером **54001** → **GUI**.
2. Нажать на трубку, чтобы снять её.
3. Набрать **54002**.
4. Открыть второй телефон.
5. При входящем вызове нажать на трубку, чтобы ответить.
6. Проверить установление соединения.
7. Положить трубки.

Повторить звонок в обратном направлении: **54002 → 54001**.

## 8. Дополнительные сервисы

Для перевода, конференции и перехвата добавить третий телефон **7960**. Подключить его порт **Switch** к **Fa0/4** коммутатора, установить адаптер питания и дождаться номера **54003**.

Дополнительные команды для базовой регистрации не нужны: порт уже настроен, номер уже создан.

**Поддержка дополнительных сервисов зависит от версии Packet Tracer.** Если в GUI нет нужной кнопки или симулятор не поддерживает необходимую настройку CME, проверить этот сервис в данной модели не получится. Приведённая базовая конфигурация из методички гарантии поддержки дополнительных сервисов не даёт. В отчёте отмечать только фактически проверенные функции.

### Перевод звонка

Если доступна кнопка **Transfer / Trnsfer**:

1. С `54001` позвонить на `54002`.
2. На `54002` ответить.
3. На `54002` нажать **Transfer**.
4. Набрать `54003`.
5. Завершить перевод кнопкой **Transfer**.
6. На `54003` ответить и проверить соединение с `54001`.

### Конференц-связь

Если доступна кнопка **Conference / Confrn** и поддерживается конференция:

1. Установить разговор между `54001` и `54002`.
2. На одном из них нажать **Confrn**.
3. Набрать `54003`.
4. На третьем телефоне ответить.
5. Снова нажать **Confrn** на телефоне, добавляющем участника.

Для конференции CME необходимы поддерживаемые линии и ресурсы. Наличие трёх зарегистрированных телефонов само по себе недостаточно для подтверждения поддержки конференции.

### Перехват звонка

Если доступна функция направленного перехвата **PickUp**:

1. С `54001` позвонить на `54002`.
2. На `54002` не отвечать.
3. На свободном телефоне `54003` нажать **PickUp**.
4. Ввести **54002** — номер телефона, на который поступает вызов.
5. При необходимости нажать **Answer**.

Названия и поведение кнопок перехвата зависят от настроек CME и поддержки симулятора.

## 9. Устранение ошибок

Если телефоны не получили номера, проверить:

1. Установлены ли адаптеры питания.
2. Подключён ли кабель к порту телефона **Switch**.
3. Находится ли интерфейс маршрутизатора `Fa0/0` в состоянии **up/up**.
4. Указаны ли правильная сеть и `option 150` в DHCP-пуле.
5. Указан ли в телефонном сервисе адрес **192.168.10.1**.
6. Созданы ли номера и включено ли автоматическое назначение.

Команды проверки на маршрутизаторе:

```text
show ip interface brief
show ip dhcp binding
show running-config
```

После исправления отключить и снова подключить питание телефонов, затем дождаться регистрации.

Если команда `telephony-service` не принимается, проверить, что выбран маршрутизатор **Cisco 2811**, как требуется в лабораторной.

## 10. Сохранение работы и оформление отчёта

На маршрутизаторе и коммутаторе выполнить:

```text
copy running-config startup-config
```

На запрос имени файла нажать **Enter**.

В Packet Tracer выбрать **File → Save As** и сохранить проект, например как **Лабораторная_2.pkt**.

Для отчёта сделать скриншоты:

- всей схемы;
- вывода `show ip interface brief`;
- вывода `show ip dhcp binding`;
- экранов телефонов с внутренними номерами;
- установленного звонка;
- дополнительных сервисов, если они были успешно проверены.

### Пример вывода после успешной проверки

В ходе лабораторной работы была собрана сеть IP-телефонии. Настроены маршрутизатор, коммутатор, DHCP-сервер и CallManager Express. Телефоны автоматически получили IP-адреса и внутренние номера. Проверены звонки между телефонами.
